# aisfhd.github.io

University labwork on script programming(lw 7-12): a personal CV website built with HTML, CSS, and JavaScript.

## Pages

- `index.html` — Home / CV (main page)
- `about.html` — About
- `resume.html` — Resume
- `services.html` — Services
- `portfolio.html` — Portfolio
- `contact.html` — Contact

## How to run

Open `index.html` in any web browser. No build step or server needed.

## Tech

HTML5, CSS3, JavaScript, Bootstrap 5
